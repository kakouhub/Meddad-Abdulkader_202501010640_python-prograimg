# IT Helpdesk Ticket Registration System

## Purpose
This program allows students to register IT helpdesk tickets for technical issues.

## Tech Stack
- Python 3
- Modular Programming

## How to Run

python main.py

## Features

- Enter student information
- Enter issue description
- Select priority level
- Automatically assign technician
- Display helpdesk ticket
